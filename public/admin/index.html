Settings & Policies

💳 Payment gateway (Razorpay)

Get keys from Razorpay Dashboard → Account & Settings → API Keys. Use rzp_test_… keys to try it out, then rzp_live_… for real payments. Keys are checked with Razorpay before saving, stored encrypted, and override the keys in .env.

In Razorpay → Webhooks, add URL with events payment.captured, payment.failed and order.paid, and use the same secret here. This marks orders paid even if the buyer closes the page.
